Stubby

A study platform that matches students with compatible study partners, then gives them real-time chat and shared study sessions. I worked on both the front-end interface and the back-end data handling.

Built for our CI/CD module, so every change went through pull requests, automated tests and a GitHub Actions pipeline before it reached the live site.

More details
  • Real-time chat with Socket.IO: typing indicators, read receipts, online presence, polls, group chats and a shared whiteboard.
  • Matchmaking on modules and study preferences, friend requests by QR code, community posts and study sessions with micro-goals.
  • Testing: around 90 Jest unit and integration test files (with Supertest) and 41 Playwright end-to-end specs.
  • CI/CD: GitHub Actions runs ESLint, Prettier and every test suite, then publishes QA reports to GitHub Pages. The app deploys to Render with a PostgreSQL database.
  • A small Python moderation service sits beside the Node.js app.

Planet Hopper

A wellness challenge app with a runner game built in: complete challenges to earn credits, buy power-ups, then hop across five planets. I built it alone, front end to database.

It's live: click Play as guest and you're in a run within seconds, no sign-up.

More details
  • Server-side anti-cheat: each run gets a signed game token tied to the player and planet, and the server times the run itself, so editing the time in the browser does nothing.
  • Auth: bcrypt password hashing, JWT access tokens and refresh tokens; every SQL query is parameterised.
  • Game: HTML canvas with jump, duck and ground-slam physics, five planets with their own speed, music and leaderboard.
  • Shop and loadout: buy Nitro Boosts and Shields, equip up to four before a run, upload a custom character skin.
  • Deployment: Express runs as a Vercel serverless function in Singapore, backed by a TiDB Cloud (MySQL-compatible) database. Uploads are stored in the database because serverless disks are read-only.
  • REST API of 30+ endpoints, designed and tested in Postman.
