Stubby

Matches students with study partners who take the same modules and like to study the same way. I built the whole chat feature, from the database and WebSocket server to the chat screen.

It was our CI/CD module project, so every change went through a pull request, automated tests and a GitHub Actions pipeline before it reached the live site.

More details
  • My part, the chat: one-to-one and group chats with typing indicators, read receipts, online status, replies, reactions, pins, @mentions, search, drafts, polls, file and voice messages, and a shared whiteboard.
  • Voice and video calls peer to peer with WebRTC, using the chat's WebSocket connection to set up each call.
  • Under the hood: a WebSocket server that checks each user's JWT before connecting, 39 REST endpoints and 11 PostgreSQL tables.
  • Testing: I wrote around 300 Jest tests and 39 Playwright end-to-end tests for the chat. The whole project has about 90 Jest test files and 41 Playwright spec files.
  • The rest of the app (team): matching on modules and study preferences, friend requests by QR code, community posts and study sessions.
  • CI/CD: GitHub Actions runs ESLint, Prettier and every test suite, then publishes QA reports to GitHub Pages. The app runs on Render with PostgreSQL.
  • A small Python moderation service runs beside the Node.js app.

Built with Node.js, Express, PostgreSQL, WebSockets, WebRTC, Jest, Playwright, GitHub Actions

Planet Hopper

A wellness challenge app with a runner game built in. You complete challenges to earn credits, spend them on power-ups, then run across five planets. I built all of it, from the game to the database.

Click Play as guest on the site and you're in a run in a few seconds. No sign-up needed.

More details
  • Anti-cheat on the server: each run gets a signed token tied to the player and planet, and the server times the run itself, so changing the time in the browser does nothing.
  • Login: bcrypt password hashing, JWT access and refresh tokens, and parameterised SQL for every query.
  • Game: HTML canvas with jump, duck and ground-slam, and five planets with their own speed, music and leaderboard.
  • Shop: buy Nitro Boosts and Shields, equip up to four before a run, and upload your own character skin.
  • Hosting: Express runs as a Vercel serverless function in Singapore with a TiDB Cloud (MySQL-compatible) database. Uploads are stored in the database because serverless disks are read-only.
  • A REST API of 30+ endpoints, tested in Postman.

Built with Node.js, Express, MySQL, JWT, HTML canvas, Vercel
